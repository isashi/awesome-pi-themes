# Security Policy

## Supported Versions

Security updates are provided for the latest published version of `awesome-pi-themes`.

## Reporting a Vulnerability

If you discover a security issue, please report it privately by opening a GitHub security advisory when available, or by contacting the maintainer through the repository:

<https://github.com/isashi/awesome-pi-themes>

Please include enough detail to reproduce and assess the issue. Do not disclose security vulnerabilities publicly until they have been reviewed.
